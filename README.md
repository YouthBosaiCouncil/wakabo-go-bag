# 防災持ち出し袋作成支援ツール

ワークショップ・授業で持ち出し品を選び、回答の集計を共有するNext.jsアプリです。

## 利用画面

- `/`: 管理者が公開したワークショップに自動参加。同じ端末から次の人が回答できます。
- `/join`: 16桁のコードでワークショップまたは授業のチームに参加。
- `/admin/login`: Firebaseのメール・パスワードで管理者がログイン。
- `/admin`: 教材編集、セッション作成、受付開始/終了、公開先の切り替え、結果・CSV。

教材は1〜100品目、回答は1〜10品目、授業は1〜50チームです。ワークショップの「回答数」は実人数ではありません。授業の再提出は同じチームの前回回答を置き換えます。

## 開発

Node.js 24、npm、エミュレーター用のJava 21を使用します。

```sh
npm ci
# .env.example を .env.local にコピーし、Firebase設定を記入
npm run dev
```

```sh
npm run lint
npm run typecheck
npm test
npm run test:emulator
npm run build
npm audit --omit=dev
```

Windowsで再現したTurbopackの子プロセス異常終了を避け、開発・本番ビルドはWebpackを使います。

## データと認可

Firestoreへのブラウザからの直接アクセスは全拒否です。`/api/workspace/*` がFirebase IDトークンの署名・失効を検証します。管理操作には非匿名アカウントの `admin: true` クレームも必要です。

参加資格・品目ID・開催回・チーム・受付状態をサーバーで確認し、回答・再送受領記録・集計を同一トランザクションで保存します。送信前にsessionStorageへ回答IDを保存するため、通信失敗や再読み込み後も同じ回答を再送できます。ストレージを使えない場合は提出前にエラーになります。

教材はバージョンを管理し、セッションに作成時のスナップショットを保存します。教材の編集・削除で過去の結果は変わりません。参加者には集計だけを返し、結果画面は30秒間隔で更新します。

詳しくは [Firebase・運用](docs/FIREBASE_GUIDE.md)、[設計・検証](docs/DEVELOPMENT.md) を参照してください。
